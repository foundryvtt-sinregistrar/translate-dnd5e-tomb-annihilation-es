# Atlas en español

28 mapas y diagramas extraídos a 240 ppp del PDF español aportado por el
usuario. Texto e ilustraciones pertenecen a sus titulares originales; no están
cubiertos por la licencia del código de este módulo.

Los recortes se han comprobado visualmente contra el PDF. Solo sustituyen
imágenes del diario Atlas, mediante el ID de página. Son mapas de referencia
para el DJ, con números de zonas, trampas y otros secretos. No deben emplearse
como fondos para jugadores.

La numeración del capítulo 2 difiere entre las ediciones. La correspondencia
se establece por localización; los pies y títulos de página de Foundry conservan
su numeración. La imagen española conserva la denominación impresa «Mina
Wyrmheart». La muralla interior de Fuerte Beluarian se recorta de su mapa general.

Las imágenes tienen la resolución efectiva del PDF: ampliarlas no recupera el
detalle del material cartográfico original de Foundry.

Procedencia, coordenadas en puntos PDF y SHA-256:
[atlas-assets.json](../../../dev-tools/translation/atlas-assets.json).
Extracción reproducible con `dev-tools/translation/extract_atlas.py` y PyMuPDF.
